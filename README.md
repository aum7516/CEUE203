# CEUE203 - Object Oriented Programming Practicals

This repository contains all Object Oriented Programming (OOP) practical assignments and solutions implemented in Java.

## Repository Structure

- **Practical-1**: Vending Machine & Toll Booth implementations
- **Practical-2**: Cinema Show & Thermostat controllers
- **Practical-3**: 2D Point calculations & Playing Card representations
- **Practical-4**: Password Checker & Chat Filter utilities
- **Practical-5**: Inheritance hierarchy (Shapes and Employees)
- **Practical-6**: Interfaces & Abstract Classes (Device Scheduler, Notification Senders, Remote Control)
- **Practical-7**: Annotations & Reflection (Form Validator, Mini Test Runner)
- **Practical-8**: Exception Handling (Guarded Calculator, Warehouse Inventory)
- **Practical-9**: Multithreading & Synchronization (Counter Race, Seat Booking Race)
- **Practical-10**: String operations & File Processing
- **Practical-11**: Java I/O & Serialization (Log Analyzer, Student Profile Serialization)
- **Practical-12**: Java Collections Framework (Unique Visitors, Word Frequency)
- **Practical-13**: Java Generics (Bounded Stats, Generic Containers, Box, Pair)
- **Practical-14**: Comprehensive Banking Application & Account Services
- **MiniBank**: Complete Core Banking System implementation (concurrency, annotations, custom exceptions, repositories, services, and unit tests)
